
# Tayhlor — Task 1: Design System

## Purpose

This project documents the design system created for the Agentic Software Bootcamp Task 1: The Design System, and Proving the Agent Used It.

The design system defines the visual rules that guide the interface, including colour, typography, and shadows. It also documents the design decisions, implementation evidence, and deliberate regression required by the task.

## Design System

The design system follows Material Design 3 guidance.

### Brand Colours

| Colour role | Hex value |
|---|---|
| Primary | `#101B2D` |
| Secondary | `#425C8A` |
| Tertiary | `#B3C5E8` |
| Neutral | `#1A1C20` |
| Neutral Variant | `#1D2028` |
| Error | `#BA1A1A` |
| Warning | `#7D5700` |
| Success | `#2E6B3E` |

### Typography

The typography system contains 15 styles across five categories:

- Display
- Headline
- Title
- Body
- Label

Each category contains Large, Medium, and Small styles. The exact specifications are documented in `docs/type-scale.md`.

### Shadows

The shadow system contains three levels:

- Soft
- Medium
- Hard

Their specifications are documented in `docs/shadows.md`.
