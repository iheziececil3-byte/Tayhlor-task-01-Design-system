    font-family: var(--font-family-display, 'Lora', serif);
    font-size: 28px;
    font-weight: 600;
    letter-spacing: 0.5px;

No line-height was specified.

The closest named style in the design system was `headline-medium`, with these values:

    Font family: Lora
    Font size: 28px
    Font weight: 600
    Line height: 39.2px
    Letter spacing: -0.476px

Finding:
The heading's font size and weight matched `headline-medium`, but the implementation used a hardcoded font size and weight, a positive letter-spacing value rather than the token's negative value, and no explicit line-height. Therefore, the heading was not fully compliant with the named typography token.
